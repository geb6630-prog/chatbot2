# 즐거운 초등학교 도서관 홈페이지

이 프로젝트는 초등학생들을 위한 귀엽고 다채로운 도서관 홈페이지입니다.
순수 HTML, CSS, JavaScript로 제작되었기 때문에 별도의 서버나 데이터베이스 없이 웹 브라우저에서 바로 실행됩니다.

## 🚀 GitHub Pages에 무료로 호스팅(배포)하는 방법

이 홈페이지는 GitHub에 올리기만 하면 전 세계 누구나 접속할 수 있는 실제 웹사이트로 만들 수 있습니다(GitHub Pages 기능). 파일 경로가 모두 상대경로로 완벽하게 설정되어 있어 곧바로 작동합니다.

1. **GitHub 저장소(Repository) 만들기**
   - GitHub(https://github.com/)에 로그인하고 새로운 Repository를 생성합니다. (예: `my-library-website`)

2. **파일 업로드하기**
   - 현재 보고 계신 이 폴더(`elementary_library_website`) 안의 **모든 내용물**(`index.html`, `css` 폴더, `js` 폴더, `images` 폴더 등)을 방금 만든 GitHub 저장소에 그대로 업로드(또는 Push) 합니다.
   - ⚠️ 주의: 폴더 자체를 올리지 말고, **폴더 안의 파일들**이 저장소 최상위 경로(Root)에 오도록 업로드해야 합니다.

3. **GitHub Pages 활성화하기**
   - 업로드한 GitHub 저장소 페이지에서 상단의 **[Settings]** 탭을 클릭합니다.
   - 왼쪽 메뉴에서 **[Pages]** 탭을 클릭합니다.
   - 'Build and deployment' 섹션에서 **Source**를 `Deploy from a branch`로 선택하고, **Branch**를 `main`(또는 `master`)으로 선택한 뒤, 폴더를 `/(root)`로 지정하고 **[Save]**를 누릅니다.

4. **웹사이트 접속하기**
   - 1~2분 정도 기다리면 설정 화면 상단에 사이트 주소(예: `https://[사용자명].github.io/my-library-website/`)가 나타납니다.
   - 해당 주소를 클릭하면 인터넷이 되는 어디서든 도서관 홈페이지에 접속할 수 있습니다!

## 🛠 주요 기능
- **스토리**: 구름빵, 무지개 물고기 줄거리 (기승전결 구조)
- **챗봇 친구**: 책 내용에 대해 대답해주는 도서관 요정 챗봇
- **미니 게임**: 구름빵 잡기 게임, 무지개 비늘 나누기 게임
